What is a network?
- A digital telecommunications network that allows nodes to share resources



Switch - A device used to forward traffic within a LAN
- Has many network interfaces/ports for end hosts to connect to
- Provide connectivity to hosts within the same LAN
- Catalyst switches -- Cisco's Enterprise-grade Switches
- Do not provide connectivity between LANs or over the internet

Router - A device that forwards traffic over the internet
- Fewer network interfaces than switches
- Used to provide connectivity between LANs
- Used to send data over the internet
- ISR - Cisco's Enterprise-grade switches


Firewall - A specialty network security device that controls traffic inside or outside of your network
- Monitor and control network traffic based on configured rules
- Can be placed 'inside' or 'outside' the network
- Known as Next-Generation Firewalls when they include more modern and advanced filtering capabilities
- Network firewalls are hardware devices that filter traffic between networks
- Software applications that filter traffic between networks
- ASA5500 - Cisco's classic firewall
- Firepower 2100 - NGF or Next Generation Firewall

Server - A device that provides services or functions for a client

Client - A device that accesses a service made available by a server
- The same device can be a client one one network and a server on another network

How big can a network be?
- As small as 2 PCs connected together
