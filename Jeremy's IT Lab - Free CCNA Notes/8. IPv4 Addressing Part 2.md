**IPv4 Address Classes**

| Class | First octect | First octet numeric range           |
| ----- | ------------ | ----------------------------------- |
| A     | 0xxxxxxx     | 0-126(127 is reserved for loopback) |
| B     | 10xxxxxx     | 128-191                             |
| C     | 110xxxxx     | 192-223                             |
| D     | 1110xxxx     | 224-239                             |
| E     | 1111xxxx     | 240-255                             |
### Class C Example
Let's take the Class C network 192.168.1.0/24;

The host portion is 8 bits or `2**8` ; that means that 256 addresses should be in that network.

If the host portion is all 0's, it's the network address, so 192.168.1.0 cannot be assigned.
If the host portion is all 1's, it's the broadcast address, so 192.168.1.255 cannot be assigned.

Therefore, the total amount of assignable addresses is from 192.168.1.1 - 192.168.1.254. So there are 254 assignable IP addresses.

### Class B example
Next, let's look at Class B network 172.16.0.0/16

The host portion is 16 bits or `2**16`; that means there are 65,536 addresses in that network.

Remember, 172.16.0.0 is the network address. 172.16.255.255 is the broadcast address. So the total amount of assignable addresses is 172.16.0.1 - 172.16.255.254. So there are 65,534 assignable IP addresses.
### Class A Example
Finally, let's look at Class A network 10.0.0.0/8.

The host portion is 24 bits, or `2**24`; that means there are 16,777,216 addresses in that network.

10.0.0.0 is the network address, 10.255.255.255 is the broadcast address. So the total amount of assignable addresses is 10.0.0.1-10.255.255.254. So there are 16,777,214 assignable IP addresses.

Next, we can go over how to configure an IP address in a Cisco device.

`show ip interface brief` - Shows the interfaces, the IPs assigned, the method by which the interface is assigned an IP, status of the interface, and the protocol. You can also use a shortened version, such as `sh ip in br`

Status - Layer 1 status
Protocol - Layer 2 status

![](/Screenshots/Pasted%20image%2020260303154914.png)

- Administratively down: Interface has been disabled with the 'shutdown' command
- This is the default status of Cisco router interfaces
- This is NOT the default status of Cisco switch interfaces
	- They will be up if connected or down if not connected.

**How to configure an interface**
`interface [interface name]`
You can also use a shortened version, like `int`

For example, `interface gigabitethernet 0/0` or even `in g0/0` would work for the picture above

Set an IP:

`ip address [ip address] [subnet mask]`

Then, we'd need to bring the interface up, like this:

`no shutdown`

For example:

`ip address 10.255.255.254 255.0.0.0`

`no shutdown`

So to configure another IP on the same router, we'd need to configure a different interface. Let's say we configure G0/1 to 172.16.0.254.

`interface g0/1`

`ip address 172.16.0.254 255.255.0.0`

`no shutdown`

And that would be configured.

And then if we wanted to configure a Class C address, like 192.168.0.254 to the g0/2 interface, it would go like this:

`int g0/2`

`ip add 192.168.0.254 255.255.255.0`

`no shut`

And voila! it would be configured.
