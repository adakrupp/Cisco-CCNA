- The the previous lesson, we went over Ethernet Frames
- The Preamble and SFD are not usually considered part of the Ethernet header
- The size of the Ethernet header + trailer is 18 bytes without them
- The minimum size for an Ethernet Frame (Header + payload or packet) + Trailer is 64 bytes
- 64 bytes - 18 bytes = 46 bytes
- Minimum payload size is 46 bytes
- If the payload is less than 46 bytes, padding bytes are added to make up for the missing bytes

### ARP - Address Resolution Protocol
- Used to discover the MAC address (Layer 2) of a known IP (Layer 3) address
- Consists of two messages
	- ARP Request
	- ARP Reply
- Sent as a broadcast Ethernet frame - sent to all hosts on the network
- ARP Reply is unicast - sent to only one host (the host that sent the request)

Below is an example of an ARP Request. Notice that the destination MAC is FFFF.FFFF.FFFF. This means that the request is broadcasting to all hosts on the network.

### Ping
- A network utility used to test reachability
- Measures round-trip time
- Uses two messages
	- ICMP Echo Request
	- ICMP Echo Reply
- Command to use ping is `ping [ip address]`

Below is what a Ping request looks like in WireShark
![](/Screenshots/Pasted%20image%2020260301133538.png)

1. An ARP request is sent out to all hosts, aka, a broadcast. It is asking who has 192.168.1.3.
2. An ARP reply is sent, letting 192.168.1.1 know that it is at MAC address 0c:2f:b0:6a:39:00
3. 4 ping requests are sent out from 192.168.1.1, followed by 4 ping replies from 192.168.1.3

On Cisco IOS software, there are a couple more commands to be familiar with:

`show arp` - shows ARP table in privileged EXEC mode

`show mac address-table` - Shows MAC address table

`clear mac address-table dynamic` - clears the MAC address table (removes all dynamic MAC addresses)

`clear mac address-table dynamic address [mac address]` - Clears a specific MAC address

`clear mac address-table dynamic interface [interface-id]` - Clears MAC addresses from a specific interface, like Gi0/0
