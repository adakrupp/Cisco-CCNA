**Layer 3 characteristics**
- Provides connectivity between end hosts on different networks (outside of the LAN)
- Provides logical addressing (IP addresses)
- Provides path selection between source and destination
- Routers operate at Layer 3

Now, looking closer at this IP address: 

192.168.1.254/24

**What does the /24 mean?**
This is a CIDR address. It means that the first 24 bits of the IP address represents the network, and the last 8 bits represent the hosts. 

So for 154.78.111.32/16, what would the /16 mean?
This would mean that the first 2 octets represent the network, and the last 2 octets represent the amount of hosts. 

So for 12.128.251.23/8, what would the /8 mean?
This would mean that the first octet represents the network, and the last 3 represent the amount of hosts.

### IPv4 Address Classes
Class A = 0xxxxxxx = 1-127 (126)
Class B = 10xxxxxx = 128-191
Class C = 110xxxxx = 192-223
Class D = 1110xxxx = 224 - 239 - Multicast addresses
Class E = 1111xxxx = 240 - 255 - Reserved (experimental)

- The range of Class A actually ends at 126, because 127 is reserved for loopback addresses. 
- This is 127.0.0.0 to 127.255.255.255
- Used to test the network stack. 
- If you ping them, the PC will send and receive them to and from itself.

| Class | First octet | First octet numeric range | Prefix Length |
| ----- | ----------- | ------------------------- | ------------- |
| A     | 0xxxxxxx    | 0-127                     | /8            |
| B     | 10xxxxxx    | 128-191                   | /16           |
| C     | 110xxxxx    | 192-223                   | /24           |

**Netmask**
Class A: /8 = 255.0.0.0
Class B: /16 = 255.255.0.0
Class C: /24 = 255.255.255.0

**Network Address**
- The host portion of a network that is all 0's (in binary - so 0) is the network address
- The network address CANNOT be assigned to a host
- The host portion of a network that is all 1's (in binary - so 255) is the Broadcast Address
- The broadcast address cannot be assigned to a host.
