### Bits and Bytes
- Bit = 0 and 1
- Byte = 8 bits
- Speed is measured in bits/second
- A gigabyte is 8 times larger than a gigabit
- Kilobit = 1000 bits
- Megabit = 1,000,000 bits
- Gigabit = 1,000,000,000 bits
- Terabit = 1,000,000,000,000 bits

Beyond terabits there are 
- Petabits
- Exabits
- Zettabits
- Yottabits
- etc
- But typically we will not see too much past Terabits for now. 

### Ethernet Standards
- Defined in the IEEE 802.3 standard in 1983
- IEEE = Institute off Electrical and Electronic Engineers

Copper Ethernet cable standards:

| Speed    | Common Name      | IEEE Standard | Informal name | Maximum Length |
| -------- | ---------------- | ------------- | ------------- | -------------- |
| 10 Mbps  | Ethernet         | 802.3i        | 10BASE-T      | 100M           |
| 100 Mbps | Fast Ethernet    | 802.3u        | 100BASE-T     | 100M           |
| 1 Gbps   | Gigabit Ethernet | 802.3ab       | 1000BASE-T    | 100M           |
| 10 Gbps  | 10 Gig Ethernet  | 802.3an       | 10GBASE-T     | 100M           |
Base = Baseband signaling
T = Twisted pair

Copper cables for ethernet are also called "UTP cables". UTP cables = unshielded twisted pair. 

There are a maximum of 8 wires. 
- 10BASE-T and 100BASE-T use 2 pairs (4 wires)
- 1000Base-T and 10GBASE-T use all 4 pairs.

## 10BASE-T and 100BASE-T
For the first two (10BASE-T and 100BASE-T), this is how things connect from a computer or router to a switch.

#### Straight through and Crossover cables
**Straight through cable**
Notice that the pairs receive on one side, and transmit on the other. This is called Full Duplex communication. The cable is called a straight-through cable.

| Port Connection Pin Position (computer or router) | Port Connection Pin Position (switch) |
| ------------------------------------------------- | ------------------------------------- |
| 1 TX                                              | 1 RX                                  |
| 2 TX                                              | 2 RX                                  |
| 3 RX                                              | 3 TX                                  |
| 6 RX                                              | 6 TX                                  |

**Crossover cable:**
Now, connecting two routers (or two switches) would have trouble because they would transmit and receive data on the same exact pins -- which would not allow them to communicate with this kind of cable. This requires a crossover cable, which reverses the pairs. Note that 'router' can be interchanged with 'PC' or "switch" on the table below as long as both are changed.

| Port Connection Pin Position (router) | Port Connection Pin Position (router) |
| ------------------------------------- | ------------------------------------- |
| 1 TX                                  | 3 RX                                  |
| 2 TX                                  | 6 RX                                  |
| 3 RX                                  | 1 TX                                  |
| 6 RX                                  | 2 TX                                  |

So, for the different devices, here is how the transmission/reception of data works:

| Device   | Transmit (Tx) Pins | Receive (Rx) Pins |
| -------- | ------------------ | ----------------- |
| Router   | 1 and 2            | 3 and 6           |
| Firewall | 1 and 2            | 3 and 6           |
| PC       | 1 and 2            | 3 and 6           |
| Switch   | 3 and 6            | 1 and 2           |
### Auto-MDI-X
Auto-MDI-X allows devices to detect which pins receive and transmit data and allow them to receive and transmit data normally. This eliminates the problem above, where a certain type of cable would need to be used depending on what connection is being made. 

## 1000BASE-T and 10GBASE-T
For Gigabit and 10-Gigabit ethernet cables, all 4 pairs are used. Each pair is bidirectional, meaning that they can either transmit or receive data.

## Fiber-Optic Connections

**SFP Transceiver** - Small Form-Factor Pluggable - A device you plug a fiber-optic cable into
**Fiber-Optic Cable** - Two connectors on each end. One transmits data, the other receives it.

![](Screenshots/Pasted%20image%2020260227123328.png)

**Multi-mode fiber**
![](Screenshots/Pasted%20image%2020260227123630.png)
- Core diameter is wider than single-mode fiber
- Allows multiple angles (modes) of light waves to enter the fiberglass core
- Allows longer cables than UTP, but shorter cables than single-mode fiber
- Cheaper than single-mode fiber due to cheaper LED-based SFP transmitters

**Single-mode fiber**
![](Screenshots/Pasted%20image%2020260227123642.png)
- Core diameter is narrower than multimode fiber
- Light enters at a single angle (mode) from a laser-based transmitter
- Allows longer cables than both UTP and multimode fiber
- More expensive than multimode fiber due to more expensive laser-based SFP transmitters

| Speed   | IEEE Standard | Informal name | Cable Type               | Maximum Length        |
| ------- | ------------- | ------------- | ------------------------ | --------------------- |
| 1Gbps   | 802.3z        | 1000BASE-LX   | Multimode or Single-Mode | 550m (MM) or 5km (SM) |
| 10 Gbps | 802.3ae       | 10GBASE-SR    | Multimode                | 400m                  |
| 10 Gbps | 802.3ae       | 10GBASE-LR    | Single-Mode              | 10km                  |
| 10 Gbps | 802.3ae       | 10GBASE-ER    | Single-Mode              | 30 km                 |

### UTP Vs Fiber-Optic

**UTP**
- Lower cost
- Shorter maximum distance
- Can be vulnerable to EMI (electromagnetic interference)
- Uses RJ45 Ports (which are cheaper than SFP ports)
- Emit a faint signal outside of the cable which can be a security risk

**Fiber-Optic**
- Higher cost
- Longer maximum distance
- No vulnerability to EMI
- SFP ports are more expensive
- Emits no signal outside of the cable, so no security risk
